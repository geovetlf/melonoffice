# MelonOffice

MelonOffice is an AI virtual office SaaS. Companies run an intelligent virtual office in which AI specialists work across departments, coordinated by GIA, the Director's executive assistant.

This repository is private and proprietary. See [LICENSE](LICENSE).

## Status

MVP in development, deployed to DEV only; not launched. What works, what was verified and what still blocks a launch is in [`docs/release/MVP-LAUNCH-READINESS.md`](docs/release/MVP-LAUNCH-READINESS.md). Architecture decisions are recorded in [`docs/adr`](docs/adr). See [CONTRIBUTING.md](CONTRIBUTING.md) for setup, commands and the architecture guardrails.

## Repository conventions

- `main` only receives changes through reviewed pull requests.
- History is never rewritten on shared branches.
- Architecture decisions are recorded as ADRs before they are implemented.
