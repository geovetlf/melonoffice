# Phase 5: moving a page onto the page components

Every page but the Home is built from the same parts, so no page looks designed on its own. This is how a page moves onto them. It changes markup and styles only: no text, message id, route, permission, request, state or behaviour.

## The parts

| Part                                                                                                    | Use                                                                                                                                                                                   | Replaces                                                                                  |
| ------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| `mo-page`                                                                                               | The page's outer element (`<article className="mo-page <page>">`).                                                                                                                    | `dept-office` outside the department office, page paddings                                |
| `PageHeader`                                                                                            | The page's one `h1`, with `description` (its line), `eyebrow` (where it sits, such as Settings), `meta` (facts) and `actions` (the page's own buttons).                               | `dept-office__title`, `connections__header`, `reports__header`, a bare `h1`               |
| `mo-panel mo-page-section`                                                                              | A part of the page, with an `h2` of class `mo-section-title`. A heading row with a control beside it is `mo-page-section__header`. Smaller headings inside are `mo-subsection-title`. | `dept-office__section` and page-specific panels                                           |
| `mo-lead`, `mo-hint`                                                                                    | A section's line of explanation; a small hint under a field or a list.                                                                                                                | `documents__lead`, `documents__hint`, `customers__meta` used as a lead                    |
| `mo-list` + `ListItem` (or `mo-list-item` with `__main`, `__heading`, `__title`, `__meta`, `__actions`) | A list of records on cards.                                                                                                                                                           | `approval-card`, `documents__item/__main/__meta/__name`, `customers__actions` in a record |
| `mo-stats` + `mo-stat` (`dt`/`dd`)                                                                      | Totals: a label and its figure.                                                                                                                                                       | `ai-usage__totals`, `command-center__figures`                                             |
| `DataTable` (`mo-table__num` on figures, `th scope`)                                                    | A table of figures. It scrolls inside its own box when there is no room, never the page.                                                                                              | `ai-usage__table`, `console__table`                                                       |
| `Toolbar`                                                                                               | The filter bar above a list: `mo-search`, `mo-chips` and a `PeriodPicker`.                                                                                                            | page-specific filter rows                                                                 |
| `PeriodPicker`                                                                                          | One period or frequency out of a few. It emits the option, as before (`aria-pressed`).                                                                                                | `period-picker`                                                                           |
| `mo-chips` + `mo-chip`                                                                                  | Filters and chip tabs (`role="tablist"` / `role="tab"` stay where they were).                                                                                                         | `memory__domains` and others as a chip row                                                |
| `mo-form`, `FormSection`, `mo-field` + `mo-label` + `mo-hint`/`mo-error`, `mo-form__actions`            | Forms: a column of fields no wider than it should be, parts with a title, the buttons at the end.                                                                                     | `business-form`, `documents__picker`, form rows with their own spacing                    |
| `StateMessage`                                                                                          | Loading (`kind="loading"`), nothing yet (`empty`), failed (`error`, announced as an alert), done (`success`), a warning. Inside a card, `inline`.                                     | `panel__empty`, `notice`, `notice--*`                                                     |
| `Button`, `mo-button--*`                                                                                | Actions: `primary` (the one main action), `secondary`, `ghost` (cancel, clear), `danger`; `sm` inside a record.                                                                       | ad-hoc buttons                                                                            |
| `mo-link`, `mo-link-button`                                                                             | A link inside running text; a record's name or a small "open" that is a button.                                                                                                       | `panel__link`, `ai-usage__row`, `reports__go`                                             |
| `Badge`                                                                                                 | A count beside a heading or a tab, a status word.                                                                                                                                     | `customers__count`                                                                        |

## Rules

- **One `h1` per page**, in `PageHeader`. Sections are `h2`; parts inside a section are `h3`, or `h2` when the page has no section above them. Never skip a level.
- **States keep their meaning**: what was `role="alert"` is `kind="error"`; what was `role="status"` is `loading`, `success` or a `warning`; a message with no role (nothing yet) is `empty`. Any text in them is unchanged.
- **Tables** are `DataTable`. On a wide screen they show whole when they fit; on a narrow one they scroll inside their box. The page never scrolls sideways.
- **Touch**: on a tablet, a phone or a touch screen, chips, segments and small buttons inside `mo-page` grow to 44 px.
- **Class names that tests or other pages read** stay until nothing reads them. A class is deleted only when `grep` finds no reference left.
- **Nothing functional moves**: no change to a message id, a value a control emits, a request, a route, a permission, the order of fields or the data shown.
