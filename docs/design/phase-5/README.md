## What was checked

| Check                | Result                                                                                                                                                      |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| One h1               | Every page, at every width: exactly one, in `PageHeader` (33 pages × 4 widths). A test fails if a page draws its own.                                       |
| Sideways scroll      | `scrollWidth ≤ clientWidth` on all 132 page/width pairs. Before, the contact card was 456 px wide at 390; now it fits. Tables scroll inside their own box.  |
| States               | Loading and nothing-yet are `StateMessage` with `status`; failures with `alert`; done with `status`. A test fails if `panel__empty` or `notice` comes back. |
| Reduced motion       | With `prefers-reduced-motion: reduce`, no animation runs on any page (spinners aside, slowed) and controls have no transition.                              |
| Touch                | Chips, segments and small buttons inside a page are 44 px on tablets, phones and touch screens.                                                             |
| The Home             | Pixel-identical before and after, empty and at work, at 1440, 1024, 768 and 390.                                                                            |
| Nothing else changed | Routes, APIs, permissions, data, message ids, auth, GIA, MelonMotor, the Harness, the CRM's logic and the 3D art are unchanged. All tests pass.             |
