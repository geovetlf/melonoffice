# ADR-0009: One main specialty per specialist

- Status: Accepted (D-29, closed by Geovet on 2026-09-26)
- Date: 2026-09-26

## Decision

Each visible specialist represents **one main specialty** (its role) on screen, in both Home modes. A specialist may hold several skills internally; skills appear in the specialist's detail panel and are never shown as separate characters or individuals.
