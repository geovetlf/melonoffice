# Troubleshooting

| What you see                                  | Meaning                                                                                                   | What to do                                                                                                       |
| --------------------------------------------- | --------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| NVIDIA never chosen                           | Working as designed: only `public` data, DEV, and a policy allowing it. Every product policy pins Gemini. | Nothing, unless a public-data use is decided.                                                                    |
| `authentication` (401/403)                    | Key missing, wrong, or not allowed this model.                                                            | Check the secret's latest version, and that `NVIDIA_API_KEY_SECRET` points at it.                                |
| `authentication` (402)                        | Trial credits are spent.                                                                                  | Request more on build.nvidia.com, or wait. The call falls back when the policy allows.                           |
| `rate_limited` (429)                          | NVIDIA's limit, which is not published.                                                                   | Handled: `Retry-After` is honoured and NVIDIA is skipped until then. Frequent 429s mean volume beyond trial use. |
| `unavailable` (404)                           | The model is not served (retired or renamed).                                                             | Run `listNvidiaModels()` and `catalogueDrift()`, then update `catalogue.ts` from the official page.              |
| `unavailable` (503) / `server_error` (5xx)    | NVIDIA outage.                                                                                            | Handled by retry and fallback.                                                                                   |
| `context_overflow`                            | Input too large for the model.                                                                            | The router picks a larger model when one fits.                                                                   |
| `invalid_response`                            | Missing usage, a malformed body or tool call, an unclosed `<think>`, or over 1 MB.                        | Check the adapter version against NVIDIA's reference.                                                            |
| Startup error `Invalid NVIDIA_API_KEY_SECRET` | The setting is not an `ai-*` Secret Manager reference. A key may have been pasted.                        | Set the reference, not the key. Rotate the key if it was pasted anywhere.                                        |
| Terraform refuses `nvidia_api_key_secret`     | Set outside `dev`, or not named `ai-*`.                                                                   | DEV only, by design.                                                                                             |
| Terraform apply fails on the secret IAM       | The secret does not exist yet.                                                                            | Create the secret first, then apply.                                                                             |
