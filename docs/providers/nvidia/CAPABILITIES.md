# Capabilities

"Integrated" means real code in MelonOffice, tested with mocks. "Verified" means an official NVIDIA page says so. Nothing is live-tested yet: that needs the key, and this environment cannot reach NVIDIA.

| Capability                            | NVIDIA official support                                                                                | In MelonOffice                                                                                                                            |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------- |
| LLM text generation                   | Verified: `POST /v1/chat/completions` ([LLM APIs](https://docs.api.nvidia.com/nim/reference/llm-apis)) | **Integrated**                                                                                                                            |
| Streaming                             | Verified: `stream` field in the chat completions reference                                             | **Integrated** (text only, whole-word release by the gateway)                                                                             |
| Tool calling                          | Verified: `tools` / `tool_choice` in the reference; "Supported" on the Nemotron 3 Nano card            | **Integrated** (calls are proposals; only the Tool Gate runs tools)                                                                       |
| Reasoning                             | Verified: `enable_thinking` on Nemotron 3                                                              | Switched **off**; traces dropped. Not registered as a capability.                                                                         |
| Structured output                     | Documented for self-hosted NIM (`nvext.guided_json`); not documented for the hosted endpoint           | **Not claimed** (UNKNOWN on hosted)                                                                                                       |
| Vision / multimodal                   | Verified per model (for example, Nemotron 3 Nano Omni)                                                 | Not integrated: no media path to NVIDIA                                                                                                   |
| Embeddings / RAG                      | Verified: `/v1/embeddings`, `input_type` query/passage, 2048-dim models                                | Not integrated: the gateway has no embeddings operation, and Company Brain has no vector store. The trial terms also forbid company data. |
| Translation                           | General LLM ability; the listed languages include Spanish                                              | Available through text generation (public text only)                                                                                      |
| TTS / STT / voice                     | Verified: Riva/Magpie over gRPC with a function id                                                     | Not integrated: MelonOffice has no voice path, and the interface is not OpenAI-compatible                                                 |
| Safety / moderation                   | Verified: NemoGuard content safety via chat completions                                                | Not integrated: the registry has no moderation capability                                                                                 |
| Image / video generation, physical AI | Listed on build.nvidia.com                                                                             | Not reviewed (UNKNOWN)                                                                                                                    |
| Model discovery                       | Verified: `GET /v1/models` ("List served models")                                                      | **Integrated** (report only, never auto-registers)                                                                                        |
